Выученные слова

Слова, которые ты уже отметила кнопкой «Знаю». Можно вернуть любое слово на повторение.

Перенос прогресса

Создай резервную копию на устройстве с выученными словами. Затем открой её на другом устройстве через «Импортировать». Импорт объединяет прогресс и собственные карточки, не стирая имеющиеся.

Добавить своё слово

Прогресс сохраняется на этом устройстве. Для работы офлайн сначала открой приложение с интернетом. Для озвучки может понадобиться системный голос.
